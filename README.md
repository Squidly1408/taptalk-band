# TapTalk Band

**A rugged, fully sealed wrist communication button for non-verbal children at school.**

TapTalk Band puts four large, clear buttons on a child's wrist. Under the buttons sits one small e-ink screen, so every button shows its own picture symbol. Press a button and the band speaks the word, vibrates, and flashes the picture. Teachers change the buttons from a phone, tablet or computer over Bluetooth.

It is built for the playground: no ports, no screws, no openings, wireless charging, a soft silicone bumper, and a target school price of about **AU$75**.

> **Status:** early design stage. Nothing here has been built or tested on real hardware yet. The firmware and app are starting points with the structure and protocol in place, not finished products. "TapTalk" is a working name; see [Brand](brand/README.md).

## Key features

| | |
| --- | --- |
| **4 clear buttons over e-ink** | 2 x 2 grid, 17 mm caps, symbols readable in full sun, zero power to hold a picture |
| **Speaks every press** | Recorded voice or text-to-speech clip per button, plus vibration and a visual flash |
| **Default + custom buttons** | Ships with 5 pages of core playground words; staff can make up to 8 pages of their own |
| **Bluetooth editing** | Paired staff devices only; pairing works only while the band is on its charger |
| **Wireless charging** | Qi-compatible receiver, magnetic alignment puck or 10-band class tray |
| **Completely sealed** | Welded shell, gel-encapsulated electronics, IP68 target, chew-safe silicone bumper |
| **Fits most wrists** | Elastic hook-and-loop band in two sizes (110-200 mm) or slip-on loop |
| **Cheap to replace** | About US$26 to build at 1,000 units |

## Getting started

**Read the design:** start with [docs/design.md](docs/design.md).

**Generate and check the default board** (needs Python 3.9+ and Pillow):

```bash
pip install pillow
python tools/make_default_board.py examples/default-board
python tools/validate_board.py examples/default-board
python -m unittest discover tools/tests
```

**Firmware** (needs ESP-IDF v5.3 or later; see [firmware/README.md](firmware/README.md)):

```bash
cd firmware
python ../tools/make_default_board.py storage_image/live
python ../tools/make_default_board.py storage_image/factory
idf.py set-target esp32s3
idf.py build flash monitor
```

**App** (needs Flutter 3.22 or later):

```bash
cd app
flutter create . --platforms=ios,android,windows,macos,web   # generates platform folders
flutter pub get
flutter run
```

## Roadmap

1. **Proof of concept** (months 1-2): dev boards, 3D-printed shell, app sends one button over Bluetooth
2. **Engineering prototype** (months 3-5): custom board, silicone samples, wireless charging, app beta
3. **School pilot** (months 6-8): 30-50 bands in 2-3 schools with speech pathologists
4. **Production prep** (months 9-12): steel tooling, certification, app store release
5. **Launch** (month 12 on): first 1,000 bands
