# Brand

Bright but calm: friendly for children, not overstimulating for sensory-sensitive students.

## Logo

The logo is the band itself: four rounded buttons, one turned into a speech bubble.

| File | Use |
| --- | --- |
| [`logo.svg`](logo.svg) | Mark + wordmark + tagline, for the box, website and docs |
| [`logo-mark.svg`](logo-mark.svg) | Mark only, in colour |
| [`logo-mark-mono.svg`](logo-mark-mono.svg) | Black and white, for the band's e-ink start-up and idle screens and the bumper emboss |
| [`app-icon.svg`](app-icon.svg) | 1024 x 1024 app icon source |

Keep clear space around the mark of at least one button-tile width. Don't recolour the tiles or put the mark on busy photos.

> **Name check:** "TapTalk" is a working name. An AAC app called TapToTalk already exists, so search the IP Australia trademark register before printing anything. The mark doesn't depend on the name.

## Typography

[Atkinson Hyperlegible](https://www.brailleinstitute.org/freefont/), a free font designed for readers with low vision. Use Bold for the labels drawn on e-ink tiles so 12-character labels stay crisp at 100 px.

## Symbols and icons

Thick rounded strokes, no fine detail, one idea per picture. App icons follow the same style.

## Device colourways

Bumper and band: Sunny Yellow, Calm Teal, Coral, Deep Ocean, and a muted Calm Grey for children who prefer low visual stimulation. Give each class or each child a colour so bands are easy to tell apart.

## App themes

Paper (light, default), Night (dark) and High Contrast. Tile previews are always black and white so staff see exactly what the e-ink shows.

## Voice

Plain and warm, written for teachers and parents: "Tap the band. Pick a picture. Press send."
